# Registro de glucosa

App web de un solo archivo para registrar niveles de azúcar en sangre y recibir alertas cuando están fuera de rango.

- Registro en mg/dL con momento (ayunas, antes/después de comer, antes de dormir), fecha, hora y nota.
- Alertas por valor bajo, alto o urgente (<54 o >300 mg/dL).
- Rangos personalizables, resumen de 7 días, gráfica de tendencia e historial.
- Los datos se guardan solo en el navegador (localStorage).

Abre `index.html` en el navegador o publícalo con GitHub Pages.

> No sustituye el consejo médico. Ajusta los rangos a las metas que te indique tu médico.
